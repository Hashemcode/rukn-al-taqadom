# Rukn Al Taqadom — company website

Bilingual (English / Arabic) website for **Rukn Al Taqadom Construction & Engineering L.L.C** —
an MEP, fire-protection and infrastructure contractor based in Dubai, United Arab Emirates.

This site is the **sister site of [Advanced Engineering House](https://www.house-engineering.com)**
(`Hashemcode/house-engineering`). Both are generated by the same Python build script and share the
same admin panel design, so anyone who can edit one can edit the other.

---

## 1. Relationship to the sister site

The two companies share a project record, so `content/projects.json` and `content/partners.json`
started as copies of the Advanced Engineering House files.

**They are independent copies.** Editing a project here does **not** change the other website, and
vice versa. To carry a newly added project across, copy its entry between the two
`content/projects.json` files (and its photo in `src/assets/img/`).

What differs from the sister site:

| | Advanced Engineering House | Rukn Al Taqadom |
|---|---|---|
| Positioning | MEP / engineering contractor | MEP, fire protection & infrastructure |
| Country | Saudi Arabia (Al Khobar) | U.A.E. (Dubai) |
| Palette | Navy + cyan | Charcoal + bronze |
| Display font | Archivo | Space Grotesk |
| Services | 9 MEP disciplines | 7 MEP-led trades |

## 2. How it fits together

```
content/*.json  ──►  python build.py  ──►  dist/  ──►  GitHub Actions  ──►  GitHub Pages
```

- **Content** lives in `content/*.json` (bilingual values, `{"en": "...", "ar": "..."}`).
- **Templates and page structure** live in `build.py`.
- **Build output** goes to `dist/` (git-ignored; produced fresh on every deploy).

## 4. Local development

```bash
python3 build.py                 # writes dist/  (standard library only, no dependencies)
python3 -m http.server 8770 -d dist
# http://localhost:8770  ·  http://localhost:8770/ar/
```

Pushing to `main` deploys — the GitHub Action builds and publishes. Once the admin panel is
connected, staff edits also commit to `main`, so always `git pull --rebase origin main` first.

## 5. Content model

Every text field is an object with English and Arabic. If Arabic is empty, English is shown.
Text from `content/*.json` is HTML-escaped at build time, so staff cannot break the layout.

```jsonc
// content/projects.json — one entry
{
  "id": "quarter-hotel",
  "name":   { "en": "Quarter Hotel", "ar": "فندق كوارتر" },
  "client": { "en": "Quarter Hotel", "ar": "فندق كوارتر" },
  "image": "p-quarter-hotel.webp",      // relative to src/assets/img/ ; "" = table row
  "categories": ["hvac", "fire", "electrical"],
  "tags":  [{ "en": "HVAC", "ar": "التكييف" }],
  "scope": [{ "en": "...", "ar": "..." }],
  "featured": true                       // show in the home page slider
}
```

Valid `categories` are defined in `build.py` → `CATS`: `hvac`, `fire`, `electrical`, `plumbing`,
`security`. Home page statistics are computed from the content, not typed.

## 6. Admin panel — not connected yet

`src/admin/` is complete and deploys to `/admin/`, but `src/admin/config.js` has an empty API
address, so the panel shows "not connected". To activate it:

1. Create a fine-grained GitHub token for **this** repository (Contents: read/write, Actions: read).
2. `cd admin-api`, create a KV namespace, set the `GITHUB_TOKEN` and `SESSION_SECRET` secrets, and
   `npx wrangler deploy` (`wrangler.toml` is already pointed at this repo).
3. Put the deployed Worker URL into `src/admin/config.js`, then create the first owner account in KV.

The sister site's `README.md` documents each of these steps in detail — the procedure is identical.

## 7. Content provenance and accuracy

Project data, partner logos and photography come from the group's company profile (Advanced
Engineering House, 34-page edition). Service descriptions were written for this company's scope
(MEP, fire protection, infrastructure and maintenance — no civil works or finishes).

**Placeholders to replace** (in the admin panel, or in `content/settings.json`):

- **Phone and emails** currently point at the sister company (`+966 59 006 8070`,
  `info@house-engineering.com`). Replace with the Dubai numbers and addresses.
- **Address** is only "Dubai, United Arab Emirates" — add the trade-licence address.
- **Working hours** are assumed Mon–Sat 8:00–18:00.
- **LinkedIn / Facebook** are empty, so those icons link nowhere until filled in.
- No trade licence number, VAT number or establishment year is published, because none was supplied.
